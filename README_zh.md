# DSH Pets

**适用于 DeepSeek Harness 的跨平台桌面宠物插件。**

[English](README.md) | [简体中文](README_zh.md)

DSH Pets 通过动态角色、预录制语音和可操作的通知，将正在运行的 AI Agent 会话呈现在桌面上。你可以快速了解多个任务的状态、一键切换到指定会话，并在任务完成或需要人工操作时收到提醒，无须反复查看 DSH Web 页面。

> **项目状态：早期开发。** 本文介绍目标功能与开发计划；列为规划的功能**不代表已经实现**。项目计划参考并继承 [zuodazuoqiang001/dsh-pet](https://github.com/zuodazuoqiang001/dsh-pet) 的实现基础，该上游项目是面向 Windows 的 DSH 桌宠插件。

## 核心功能

产品围绕四个模块设计：

| 模块 | 规划能力 |
| --- | --- |
| **会话管理（Session Management）** | 展示正在运行的 DSH 顶层会话、快速切换会话；在任务完成、失败及等待授权时提醒，并保留未读通知。 |
| **角色系统（Character System）** | Spine 角色与精灵图桌宠、模型身份与角色绑定、Agent 状态到动作和表情的映射。 |
| **语音系统（Voice System）** | 根据事件播放**预录制的固定语音**，支持角色专属语音包、音量、静音、防重复播报和可选口型同步。 |
| **桌面交互（Desktop Interaction）** | 透明悬浮窗口、拖拽和位置记忆、系统托盘、鼠标穿透、免打扰模式及基础性能设置。 |

**两项不可妥协的核心指标：**

1. **快速切换正在运行的会话：** 从桌宠会话列表或气泡直接进入指定 DSH 会话。
2. **可靠的任务完成提醒：** 任务结束后主动提醒，并能直接定位到对应会话。

角色动画和语音负责增强角色表现。即使关闭动画、静音或模型加载失败，会话切换和提醒功能也必须正常工作。

## 交互示例

- **正在执行：** 角色进入工作动画，气泡展示当前运行中的会话。
- **等待授权：** 角色播放提醒动作，点击气泡即可进入需要处理的会话。
- **任务完成：** 播放完成动画及可选的预录制台词，通知在用户查看前仍可追溯。
- **空闲：** 使用轻量的呼吸、眨眼或待机动作，尽量减少对桌面工作的干扰。
- **多个 Agent 并发：** 对通知排队或合并，避免多个角色同时发声。

计划允许按模型系列（如 DeepSeek、Claude、GPT）分配角色，也允许用户手动覆盖。会话仍通过**会话 ID** 唯一识别，即使会话使用的模型发生变化也不影响定位。

## 计划采用的技术架构

```text
DeepSeek Harness（DSH Web / Cordis 插件）
  ├─ Agent 与会话状态采集
  ├─ 任务完成、失败、等待授权事件
  └─ 会话定位与跳转
                 │
                 │ 本机受限通信
                 ▼
Electron 桌面客户端（主进程）
  ├─ 连接管理、通知管理、会话管理
  ├─ 桌面窗口、系统托盘、平台适配
  └─ React + TypeScript 界面
       ├─ 会话气泡、通知历史
       ├─ Spine 渲染器（主角色格式）
       ├─ 静态图降级（无 GPU / 低耗模式）
       └─ 预录制语音播放、可选口型同步
```

**目标平台：** Windows、Linux、macOS。首个桌面验收环境计划采用 **Ubuntu 24.04 Desktop + DSH Web**，再逐步完善 Windows 与 macOS 的测试。Linux 的 X11/XWayland 与原生 Wayland 对全局定位、窗口置顶和焦点切换存在不同限制，具体支持范围以实测结果为准。

### 角色资产

每个角色是一个自包含目录，只有一个契约文件。默认角色随安装包发布；其余角色按需下载到用户数据目录，同名时用户目录优先于内置副本。

```text
assets/characters/                 # 内置，只读
  index.json                       # 可下载角色索引（版本、sha256、下载地址）
  deepseek/                        # 唯一随包发布的角色
    manifest.json
    LICENSE
    preview.webp
    spine/                         # Spine 骨骼、图集与贴图
    voice/                         # 预录制状态语音（可按事件缺省）

~/.dsh/pets/characters/<id>/       # 下载而来，可写，优先于内置副本
```

`manifest.json` 是唯一契约，运行时**不靠约定文件名**猜资源。它声明 Spine 入口与缩放、锚点，Agent 状态到动画的映射（`idle`、`working`、`attention`、`done`、`failed`），每个事件对应哪些语音，以及无 GPU 加速时使用的静态图降级。某个事件没有语音时留空即可，该事件保持静音。

以上是**已确定的目标结构**，尚未实现。语音由开发者**提前录制或生成**，随角色资源包发布。运行过程中**不要求实时 TTS 推理**，无需强制接入语音 API，也无需将会话正文发送给语音服务。

角色立绘、骨骼动画和配音可以在开发阶段利用第三方工具离线制作；这些资产生产工具不随 DSH Pets 运行时一起安装。

## 可靠性、隐私与资源占用

重点遵循以下设计原则：

- 优先依据明确的任务生命周期事件判断结果；**连接中断不等于任务成功完成**。
- 完成事件去重，保存未读消息，并在 DSH 支持的范围内于重连后恢复状态。
- 角色渲染、音频或 GPU 加速不可用时，仍保留会话切换和通知功能。
- 默认使用本地受限通信，避免无鉴权地暴露桌宠控制接口；远程连接需单独做好安全配置。
- 默认不朗读代码、密钥和完整会话内容；固定语音只负责播报预定义的**状态提示**。
- 提供静音、免打扰、低资源占用等设置，适合长期桌面常驻。

以上是**工程目标**，并非功能完成声明或安全审计结论。
